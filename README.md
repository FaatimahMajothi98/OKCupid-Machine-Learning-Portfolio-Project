# OKCupid Machine Learning Portfolio Project
### By Faatimah Majothi

#### Introduction:
This project was created for the ["Data Scientist: Machine Learning Specialist career path" portfolio project](https://www.codecademy.com/paths/data-science/tracks/dscp-machine-learning-portfolio-project/modules/dscp-group-project-okcupid-date-a-scientist/informationals/dscp-group-project-okcupid-date-a-scientist) task on [Codecademy](https://www.codecademy.com/learn), with the intention of showcasing the machine learning skills developed over the course of the career path.
Inspiration for some of the machine learning models was taken from the OKCupid project by [nsmith7atafi](https://github.com/nsmith7atafi/OKCupid_Project/tree/main) on GitHub.

#### Project Goals:
- Clean, explore and preprocess data using `Python` libraries.
- Build, train and test machine learning algorithms
- Use feature engineering, feature selection and hyperparameter tuning to optimise model performance
- Present work in a clear, understandable and professional format

#### Contents:
The complete project is available in the Jupyter notebook 'machine-learning-portfolio-project.ipynb'. The final presentation is available in the 'OKCupid – Machine Learning Analysis.pptx' PowerPoint file. Downloading the file may be necessary for viewing.

All of the core project details can be found in the Jupyter notebook, and any feedback or suggestions would be greatly appreciated.

Thank you for taking the time to review this project!
